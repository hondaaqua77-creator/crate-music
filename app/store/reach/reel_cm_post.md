# reel_cm.mp4 投稿キット（Instagram トライアルリール）

## 投稿手順（iPhone・5分）
1. reel_cm.mp4 と reel_cm_cover.jpg をiPhoneに保存（AirDrop／ファイル）
2. Instagram → ＋ → リール → reel_cm.mp4 を選ぶ → 次へ
3. 音源：「オーディオを追加」→ 落ち着いたピアノ系のおすすめから1曲（音量：動画0％・音源100％）
4. 次へ → カバーを編集 → 「カメラロールから追加」→ reel_cm_cover.jpg → プロフィールグリッドの位置を中央に
5. キャプションを下の文面で貼り付け
6. 「AIラベル」をON（Metaの生成コンテンツ表示。入れないとリーチ制限の恐れ）
7. 「トライアルリール」をON（フォロワー以外にだけ先に配信）→ シェア
8. 24時間後：インサイトの再生数・完視聴率・プロフィールアクセスを確認 → 良ければ「全員に公開」
