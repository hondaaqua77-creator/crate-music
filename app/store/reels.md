# CRATE Instagramリール 広告計画

対象：印刷楽譜を使う人（ピアノ・ギター弾き語り、合唱・吹奏楽、カラオケ練習、音楽教室の先生）
ゴール：App Storeリンクへの誘導（プロフィールのリンク）。リールは**無音でも伝わる**ように、画面文字で話を運ぶ。
リンク：https://apps.apple.com/jp/app/id6830933661（プロフィールに設置。反映後に有効）

## 前提ルール

| ルール | 理由 |
|---|---|
| 冒頭3秒で「何ができるか」を文字＋映像で見せる。挨拶・ロゴなし | 3秒で伸びるか決まる |
| 15〜30秒。長くしない | 完視聴率が最重要 |
| TikTok/CapCutの透かし入り動画は使わない（透かしなしで書き出す） | 透かしは配信が絞られる |
| 画面文字は中央〜やや上に。下1/4と右端はUIに隠れる | 安全領域 |
| 音声はオリジナル（自分の声または操作音）。流行音源は投稿時にアプリ内で追加 | 権利 |
| 他人の市販楽譜を映さない。自作・著作権切れの楽譜（アプリ内サンプル）を使う | 著作権 |
| 「無料」はOK、「ずっと無料」「完璧に読み取る」は書かない | 誇大表現 |

## リール1（本命）：「写真を撮るだけで移調」 20秒

**1本の主張**：印刷楽譜をキー変更する手作業が、写真1枚で終わる。
**送りたくなる相手**：「このキーで歌いたい」と頼まれる伴奏者／合唱・バンド仲間。

| 秒 | 映像 | 画面文字（太字・中央） | 声（任意） | 音 |
|---|---|---|---|---|
| 0–3 | 机の上の紙の楽譜にiPhoneをかざす。シャッター音 | **楽譜、写真撮るだけで移調できます** | 「楽譜のキー変え、写真でできます」 | シャッター音 |
| 3–7 | アプリ画面：読み込まれた楽譜が表示 → ♯ボタンを2回タップ | **♯を2回 → 全音上げ** | 「♯を押すだけ」 | タップ音 |
| 7–12 | 音符と調号が書き換わるアニメーション（画面録画） | **音符も調号も書き直し** | — | — |
| 12–16 | 「PDF保存」→「送る」→ LINEの共有画面 | **PDFでLINEに送れる** | 「そのまま共有」 | — |
| 16–20 | 再生ボタン → 再生中の画面。最後に冒頭と同じ机のカット（ループ） | **CRATE　無料・iPhone/iPad**　プロフィールのリンクから | 「CRATE、無料です」 | 再生音（著作権切れ曲） |

カバー：0–3秒の「楽譜にiPhoneをかざす」フレーム＋文字「写真撮るだけで移調」。

**キャプション**
```
楽譜の移調、写真を撮るだけでできます。

印刷した楽譜をiPhoneで撮る→♯♭ボタンでキー変更→PDFでLINEに送る。
歌う人のキーに合わせて書き直す作業がなくなります。
読み取りミスはタップで直せます。

無料（広告あり／広告なし版1,200円）・iPhone/iPad
→ プロフィールのリンクからApp Storeへ

#楽譜 #移調 #弾き語り #ピアノ伴奏 #合唱
```

## リール2（共感型）：「伴奏者あるある」 15秒

**1本の主張**：「半音下げて」と言われた瞬間の苦労が消える。
**送りたくなる相手**：歌い手→伴奏者（「これ使って」）、伴奏者→歌い手（「これで何キーでもOK」）。

| 秒 | 映像 | 画面文字 | 声 | 音 |
|---|---|---|---|---|
| 0–3 | 楽譜を前に固まる本人（顔なしでも可、手元） | **「半音下げて」って言われた日** | — | 無音→ため息 |
| 3–6 | 鉛筆で書き直そうとして止める | **全部書き直し…だったのが** | — | — |
| 6–11 | iPhoneで撮影 → ♭を1回タップ → 楽譜が変わる | **写真→♭1回で終わり** | 「はい終わり」 | タップ音 |
| 11–15 | 完成した楽譜を伴奏しながら見せる。最後に0秒目の構図に戻る | **CRATE　無料**　リンクはプロフィール | — | 伴奏音 |

カバー：0–3秒＋文字「半音下げてって言われた日」。

**キャプション**
```
「半音下げてもらえますか？」
その場で楽譜を書き直していた人へ。

写真を撮って♭を1回。音符も調号も書き換わります。
CRATE（無料・iPhone/iPad）→ プロフィールのリンク

#伴奏 #弾き語り #移調 #楽譜 #カラオケ練習
```

## リール3（使い方30秒）：「3ステップ」

**1本の主張**：読み込む→移調→送る、の3手順を実際の操作速度で見せる（保存されやすい）。

| 秒 | 映像 | 画面文字 | 声 |
|---|---|---|---|
| 0–3 | アプリ画面全体 | **楽譜アプリCRATEの使い方 3ステップ** | 「3ステップです」 |
| 3–10 | ①「楽譜を追加」→ 写真／PDFを選ぶ → 読み込み完了 | **① 写真かPDFを読み込む** | 「写真でもPDFでも」 |
| 10–18 | ②「移調」→ ♯♭ → 元のキーを選ぶ → 調号が変わる → 音符をタップして直す | **② ♯♭で移調　読み取りミスはタップで修正** | 「間違いはタップで直せます」 |
| 18–26 | ③ 再生 → 「PDF保存」→「送る」 | **③ 再生して、PDFで送る** | 「練習して、送る」 |
| 26–30 | 設定画面の「広告なし版 ¥1,200」を一瞬 → 冒頭画面 | **無料　広告なし版は1,200円**　保存しておくと便利 | — |

カバー：文字「使い方 3ステップ」＋アプリ画面。

**キャプション**
```
楽譜アプリCRATEの使い方（30秒）
①写真かPDFを読み込む ②♯♭で移調 ③再生してPDFで送る

無料・iPhone/iPad。広告なし版は1,200円（買い切り）。
後で見返す用に保存どうぞ。

#楽譜アプリ #移調 #音楽教室 #ピアノ #ギター
```

## 撮影の準備

| もの | 内容 |
|---|---|
| 楽譜 | アプリ内の「サンプル楽譜」（著作権切れ）を印刷したもの。市販楽譜は映さない |
| 画面録画 | iPhoneの画面収録（コントロールセンター）。通知はオフ（集中モード） |
| 手元撮影 | 自然光、机の上。縦9:16 |
| 編集 | iPhoneの「写真」アプリかInstagram内で結合。CapCutを使う場合は透かしなしで書き出し |
| 文字入れ | Instagram投稿時に入れると、字幕として検索に拾われやすい |
