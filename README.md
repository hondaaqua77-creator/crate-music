# CRATE — Personal Music Library（独立版）

手持ちの音楽ファイルを取り込み、整理・プレイリスト作成・再生ができる音楽ライブラリアプリです。
Claudeや外部サーバーには一切依存しません。曲ファイル・評価・メモ・プレイリストはすべて**利用者の端末内（ブラウザの保存領域）**に保存され、どこにも送信されません。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・機能のすべて） |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ名・アイコン設定 |
| `sw.js` | オフライン起動用（一度開けば電波がなくても起動できる） |
| `vendor/jsmediatags.min.js` | 曲名・ジャケット画像を読み取るライブラリ（同梱済み） |
| `icons/` | アプリアイコン |

このフォルダを**丸ごと**サーバーに置くだけで動きます。データベースやサーバー側のプログラムは不要です。

## 公開方法（どれか1つ）

| 方法 | 費用 | 手順の概要 | 向いている用途 |
|---|---|---|---|
| Netlify | 無料枠あり | アカウント作成 → 新しいサイトを作り、このフォルダをドラッグ＆ドロップでアップロード | 一番手軽。まず試すならこれ |
| Cloudflare Pages | 無料枠あり | アカウント作成 → Pages で新規プロジェクト → フォルダを直接アップロード | 表示が速い。独自ドメインも簡単 |
| GitHub Pages | 無料 | GitHubにリポジトリを作りファイルを置く → 設定の Pages で公開 | 更新履歴を残して管理したい場合 |
| 自社サーバー | 契約による | 公開フォルダ（例：`/music/`）にアップロード | 既存のドメイン配下で運用したい場合 |

※ 公開先は **https（鍵マーク付き）** にしてください。httpだとオフライン起動とホーム画面アプリ化が動きません。上記の3サービスは自動でhttpsになります。

## パソコンだけで試す場合

ファイルを直接ダブルクリックすると一部機能が動かないため、簡易サーバーで開きます。

```
cd crate-app
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## スマホでの使い方

| 手順 | iPhone（Safari） | Android（Chrome） |
|---|---|---|
| ① | 公開したURLを開く | 公開したURLを開く |
| ② | 共有ボタン →「ホーム画面に追加」 | 「︙」→「アプリをインストール」または「ホーム画面に追加」 |
| ③ | ホーム画面のCRATEから起動 → 「曲を取り込む」で「ファイル」アプリの曲を選ぶ | 起動 → 「曲を取り込む」で端末内の曲を選ぶ |

## 利用者に伝えておくこと

| 項目 | 内容 |
|---|---|
| データの保存先 | 端末のブラウザ内。サーバーには何も送られない |
| 端末を変えるとき | 「設定・バックアップ」→「バックアップを書き出す」→ 新しい端末で読み込み → 同じ曲ファイルを取り込むと整理内容が復元される |
| データが消えるとき | ブラウザの「履歴・サイトデータの削除」を行うと消える。定期的なバックアップを推奨 |
| 自動削除の防止 | 曲を取り込むと「曲の保護」を自動で申請。保護されていない場合は画面上部の案内から「保護する」を押す。iPhoneはホーム画面に追加して、そこで曲を取り込むと保護される |
| iPhoneの注意 | 「ミュージック」アプリ内の曲はブラウザから読めない。「ファイル」アプリかGoogleドライブに置いた曲が対象 |

## 更新するとき

`index.html` を差し替えたら、`sw.js` 1行目付近の `VERSION = 'crate-v1'` を `crate-v2` のように1つ上げてからアップロードしてください。利用者の端末に新しい版が確実に配信されます。
